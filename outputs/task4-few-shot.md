# Task 4 — Few-Shot Prompting

**Objective:** Improve the tourism webpage by giving GitHub Copilot examples to follow.

**Technique:** Few-Shot Prompting

**Prompt:**

Create a tourism guide about Marinduque, Philippines. Follow the examples below for the format and writing style of each tourist attraction.

**Example 1:**

Name: Poctoy White Beach  
Location: Torrijos, Marinduque  
Description: Enjoy the white sand, clear waters, and relaxing coastal scenery.

**Example 2:**

Name: Bathala Caves  
Location: Santa Cruz, Marinduque  
Description: Explore natural cave formations and appreciate the island's natural beauty.

**Your Task:**

Create a webpage featuring at least five tourist attractions in Marinduque. Follow the examples by providing the attraction name, location, and a short description for each. Use an organized card layout, readable text, attractive colors, and a responsive design.

Use HTML, CSS, and JavaScript as appropriate. Save the generated webpage as `outputs/task4-few-shot.html` without overwriting the previous task files.
